# OffTorque status

Machine-generated status feed for offtorque.com, written every 5 minutes by
this app repo's `.github/workflows/uptime-monitor.yml`. Not meant to be
edited by hand.

- `status.json` — read by the app itself (via `raw.githubusercontent.com`)
  to show an outage banner even when Supabase/Netlify are both down.
- `state.json` — the monitor's own failure-counter/incident state, not
  read by the app.
